# `openapi/_original/`

Pristine, pre-refine copies of the derived OpenAPI documents in `../`. Kept so version and
drift checks have an unmodified baseline to read. These are byte-identical to the documents
first written on 2026-08-19; if `refine-openapis` later splits or rewrites the working copies,
these do not change.

Provenance for every file here: `generated: 2026-08-19`, `method: derived`,
`source: live unauthenticated probes of University of Oxford endpoints, payloads in ../../examples/`.

None of these documents is published by the University of Oxford. Oxford publishes prose
documentation for its OAI-PMH interface at https://ora.ox.ac.uk/api and prose about IIIF at
https://digital.bodleian.ox.ac.uk/faq/, and no machine-readable API contract of any kind.
